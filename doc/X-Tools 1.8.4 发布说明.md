# X-Tools 1.8.4 发布说明（2026-09-09）

## 概述

X-Tools 1.8.4 版本在 1.8.3 的基础上，为词典查词新增了通配符（简易正则）检索能力，并移除了容易引起混乱的同义词机制，同时修复了 Markdown 编辑/预览切换显示旧内容的问题。

## 主要更新

### 1. 词典查词：支持通配符（正则）

- **单字符匹配** - `?` 或 `？` 代表任意一个字符，例如 `?at` 可命中 cat、bat
- **多字符匹配** - `*` 代表任意多个字符（可为零个），例如 `comput*` 可命中 computer、computing
- **结束标记** - `$` 或 `￥` 放在末尾表示"到此结束"，例如 `tion$` 命中 attention，不命中 tional
- **不再走模糊匹配** - 搜索词中只要含有上述字符，即按正则方式检索，不再执行原来的包含/放宽匹配，结果更可预期
- **结果与性能** - 命中结果按词条长度升序排列（更贴近模式的词在前），单次最多返回 500 条，避免过宽模式刷屏
- **特殊字符安全** - 其余字符一律转义，任何输入都能得到合法正则（如 `c+*` 可正确匹配 `c++`）

### 2. 词典：移除同义词（terms）机制

- **词条即标题原文** - 不再把标题按符号拆成多个"同义词"，词条统一使用标题完整原文，例如 `测试词条 Test Term` 保持原样
- **查词结果更聚焦** - 检索只比对词条本身，不再出现同义词各占一条、主词条被截断的混乱情况

### 3. Markdown 编辑体验修复

- **切换不再显示旧内容** - 修复编辑后切换到预览再切回编辑时，仍显示修改前内容的问题

## 其他

- **名称规范化** - 应用与打包名称统一规范为 X-Tools
