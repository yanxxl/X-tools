# X-Tools 1.8.3 发布说明（2026-09-08）

## 概述

X-tools 1.8.3 版本在 1.8.2 的基础上，重点优化了 Markdown 大文件的加载性能与渲染效果，并对词典查词功能进行了性能重构，提升了整体阅读与查词体验。

## 主要更新

### 1. Markdown 大文件加载优化

- **分块加载** - 优化大文件加载机制，提升 Markdown 大文件的打开与渲染速度
- **性能提升** - 引入后台处理逻辑，降低大文件预览时的卡顿

### 2. 词典性能优化

- **解析重构** - 重构词典解析逻辑，拆分核心解析模块，提升查词响应速度
- **并行处理** - 借助线程池并行解析，加快词典加载

### 3. Markdown 预览体验改进

- **保留多余换行** - 预览时保留原文中多余的换行，更贴近原始排版
- **换行修正** - 修复部分场景下换行处理异常的问题
