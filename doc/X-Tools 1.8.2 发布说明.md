# X-Tools 1.8.2 发布说明（2026-08-14）

## 概述

X-tools 1.8.2 版本在 1.8.1 的基础上，新增了 AI Chat 集成功能，让用户在阅读文档时可以随时向 AI 提问，同时改进了 Markdown 阅读体验和文件管理操作。

## 主要更新

### 1. AI Chat 集成（全新）

- **边阅读边问 AI** - 在阅读文档时集成 AI Chat，支持随时向 AI 提问
- **会话排序** - 支持对会话列表进行排序

### 2. Markdown 阅读体验优化

- **记住边栏宽度** - 记住 Markdown 视图边栏的宽度
- **代码显示改善** - 优化 Markdown 预览中代码块的显示效果
- **公式与图修复** - 修复代码行号处理影响数学公式和图显示的问题
