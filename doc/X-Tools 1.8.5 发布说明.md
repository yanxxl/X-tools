# X-Tools 1.8.5 发布说明（2026-10-20）

## 概述

X-Tools 1.8.5 版本在 1.8.4 的基础上，新增了全局深色模式，所有查看器与工具窗口都能随主题一并切换；同时修复了空 Markdown 文件长时间停留在"正在解析"的问题，并完成了源码结构的三包重构。

## 主要更新

### 1. 深色模式（重点功能）

- **一键切换** - 标题栏边栏控制区新增深浅色切换按钮，随时在浅色/深色之间切换
- **跟随系统** - 首次使用时默认跟随系统外观，用户手动选择后会被记住，下次启动沿用
- **组件库同步** - 基于 antd 的主题算法统一切换组件配色，静态的 message、Modal 弹窗也会同步主题，不再出现"深色界面弹浅色弹窗"
- **语义化配色** - 抽取 `--xt-*` 语义化 CSS 变量，替换各查看器与工具窗口中硬编码的颜色，主题切换时界面过渡统一、无残留色块
- **内容区适配** - Markdown 代码高亮、CodeMirror 编辑器随主题切换配色，阅读与编辑时对比度一致
- **覆盖范围** - 文件树、全局搜索与预览、Markdown/文本/图片/PDF/Office/视频查看器、AI Chat、词典、文件信息、文件历史、设置等窗口全部适配

### 2. 空 Markdown 文件修复

- **不再卡在解析中** - 修复空文件或纯空白内容的 Markdown 一直显示"正在解析"的问题，此前渐进渲染不会启动，首屏占位始终不消失
- **明确空状态** - 解析完成但没有内容时直接进入完成状态，并显示"文件内容为空"的提示

### 3. 代码结构重构

- **三包分层** - 源码拆分为 `main`（主进程、preload、Office 解析、线程池）、`renderer`（React 界面、组件、contexts）、`shared`（类型与共用工具）三个包
- **路径别名** - 引入 `@main`、`@renderer`、`@shared` 别名，跨包引用更清晰
- **构建同步** - tsconfig、Vite、Electron Forge、入口 HTML 与测试引用同步更新，打包产物结构不变，使用方式无差异

## 其他

- **脚本清理** - 移除已迁移到网站上的图标生成脚本，精简仓库内容
