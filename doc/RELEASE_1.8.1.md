# X-tools 1.8.1 发布说明（2026-05-14）

## 概述

X-tools 1.8.1 版本在 1.8.0 的基础上，新增了视频字幕生成功能、文本文件编码转换和简繁体转换等实用特性，同时改善了命令行操作体验。

## 主要更新

### 1. 视频字幕生成

- **自动生成字幕** - 支持为视频文件自动生成字幕

### 2. 文本文件处理增强

- **编码转换** - 支持将文本文件转换为 UTF-8 编码
- **简繁转换** - 支持文本文件简体与繁体中文互转

### 3. 命令行体验优化

- **命令模式改善** - 优化命令行交互体验

### 4. 问题修复

- 修复文件树文件夹图标状态显示问题
- 修复文件树右键菜单分隔符显示问题
