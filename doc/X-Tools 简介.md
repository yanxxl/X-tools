## X-Tools 简介

X-Tools 是一款免费、开源的本地资料库浏览与管理工具，基于 Electron、React 和 TypeScript 构建，支持 Windows 与 macOS。

它以文件树方式管理本地文档、笔记和学习资料，提供多窗口浏览、文件增删改与批量操作、拖拽导入导出。内置 Markdown、PDF、Office、图片、音视频及字幕预览，支持跨格式多线程全文搜索、Markdown 编辑与语音朗读、视频多字幕播放、以 Markdown 为词典的查词，以及终端调用等能力，适合学习资料整理与文档快速检索。

### 推介语

给本地资料一个安家之处：X-Tools 免费开源，文件树、多窗口、拖拽导入，一个入口管好所有笔记与文档。

Markdown、PDF、Office、音视频、字幕，打开就能看；跨格式全文搜索多线程并发，几秒定位到那句话。

写笔记有大纲导航与语音朗读，看课程有多字幕切换与进度记忆，查单词可以用 Markdown 当词典，学习动线一气呵成。

不联网、不上传、不订阅，数据始终留在自己的磁盘上；Windows 与 macOS 均可使用，下载即用。
